## 1. What cm2d does

`cm2d run` is one process that:
1. Receives Claude Code hook events over HTTP on `127.0.0.1:47731` (configurable).
2. Watches Herdr with `internal/herdr.Watcher`.
3. Keeps a session table: Claude sessions in any frontend plus every agent in Herdr.
4. Assigns up to 10 sessions to the 10 session keys and paints their state on the pad.
5. Handles key presses: session key = select + focus; dial turn = move selection; APPROVE / DENY answer a
   held PermissionRequest of the **selected** session only.

## 2. Facts the code must respect (verified)

- Pad keys (Layer 2): session keys `AG00`–`AG09` (slot 0–9, reading order). APPROVE = wide key = `AG10` and `AG11`:
  one press reports both within ~5 ms, so treat any AG10/AG11 press within 80 ms of the last as the same press.
  DENY = `AG12`. Dial: `ENC_CW` (+1) / `ENC_CC` (−1), `act:2`, one event per detent. Key press = `act:1`
  (ignore `act:0` releases). Dial press switches layers in firmware and sends nothing.
- Notification shape: `{"m":"v.oai.hid","p":{"k":"AG03","act":1}}` (the device client exposes Notification{Method,Params}).
- Lights: `v.oai.thstatus` with a bare array of `{"id":N,"c":0xRRGGBB,"b":0..1,"e":E,"s":S}`; thread N lights the
  key bound to AG<N>. E: 0 off, 1 solid, 4 breathing. **Breathing needs `s` (use 1.0)**. Replies are always
  `{"ok":1}`; follow each change burst with one full reconcile ~500 ms later. Thread state persists across layers.
- Claude hook payloads always carry `session_id`, `cwd`, `hook_event_name`. PermissionRequest adds `tool_name`,
  `tool_input`, optional `agent_id`/`agent_type`, `permission_mode`. Notification adds `notification_type`
  (`permission_prompt`, `idle_prompt`, ...). StopFailure replaces Stop after an API error.
- `SessionStart` does not fire HTTP hooks; it must be a **command** hook. Command hooks see the true
  `CLAUDE_CODE_SESSION_ATTENDED` ("1" interactive, "0" headless); `CLAUDE_CODE_ENTRYPOINT` is
  `claude-desktop` | `cli` | `sdk-cli` (inherited by nested runs, so attended wins); `HERDR_PANE_ID` is set in
  Herdr panes. HTTP hooks may send env values as headers only via `allowedEnvVars`, and those values are the
  *inherited* ones (unreliable for attended).
- PermissionRequest hold (Design A): the normal dialog stays live; first answer wins; empty 200 = no decision.
  allow = `{"hookSpecificOutput":{"hookEventName":"PermissionRequest","decision":{"behavior":"allow"}}}`;
  deny = same with `"behavior":"deny","message":"Denied from the macropad"`. A plain allow does NOT answer
  AskUserQuestion; for AskUserQuestion and ExitPlanMode (a plan to read) reply empty 200 at once. A terminal answer gives no reliable HTTP signal,
  so a held request is released (empty 200) on PostToolUse, Stop, StopFailure, UserPromptSubmit or SessionEnd for
  the same session, when the client disconnects, or after MaxHold (default 590 s; the hook timeout is 600 s).
- Focus: Herdr pane = `herdr.Client.Focus(pane)` then `open -a Ghostty`; desktop session =
  `open "claude://resume?session=<session_id>"`; other CLI session = `open -a Ghostty`.

## 3. Packages and interfaces (builders must match these exactly)

### 3.1 `internal/session` (pure, no I/O, not goroutine-safe; owned by the run loop)

```go
type Frontend string // "desktop", "herdr", "terminal", "unknown"
type State int       // Idle, Working, NeedsInput, Done, Error (Done = finished and not yet seen)

type HookEvent struct {
    Name             string // SessionStart, UserPromptSubmit, Stop, StopFailure, SessionEnd,
                            // Notification, PostToolUse, PermissionRequest, PermissionReleased
    SessionID, CWD   string
    Attended         string // "1", "0", "" (unknown) — from the SessionStart command hook only
    Entrypoint       string // claude-desktop | cli | sdk-cli | ""
    HerdrPane        string
    Source           string // SessionStart source: startup|resume|clear|compact
    NotificationType string
    ToolName         string
    RequestID        string // PermissionRequest / PermissionReleased: id from the hooks package
    IsQuestion       bool   // PermissionRequest for AskUserQuestion
    At               time.Time
}

type Session struct {
    Key        string   // "claude:<session_id>" or "herdr:<pane_id>" (non-Claude Herdr agent)
    SessionID  string   // Claude session id, "" for non-Claude
    HerdrPane  string
    Kind       string   // agent kind: "claude", "codex", ...
    Frontend   Frontend
    CWD, Label string   // Label = cwd basename, plus " ·" + 4 chars of id when two labels collide
    State      State
    Pending    []Pending // held permission requests, oldest first
    Question   bool      // AskUserQuestion is showing
    LastActive time.Time
    Ended      bool
    EndedAt    time.Time
    Slot       int       // 0..9, or -1
}
type Pending struct{ RequestID, Tool string; Since time.Time }

type Config struct {
    Slots          int           // 10
    EndedGrace     time.Duration // keep an ended session's slot this long (default 10m; desktop may resume)
    IdleExpiry     time.Duration // free a slot after this long with no events (default 30m), never while NeedsInput/Working
    NeedsInputDelay time.Duration // a PermissionRequest shows as NeedsInput after this long pending (default 1s)
    IgnoreCWDPrefixes []string    // default: ~/elara
}

func New(cfg Config) *Table
func (t *Table) ApplyHook(ev HookEvent)
func (t *Table) ApplyHerdr(s herdr.Snapshot, now time.Time)
func (t *Table) Focused(key string, now time.Time)   // marks seen: Done -> Idle
func (t *Table) Tick(now time.Time)                  // expiry and slot freeing
func (t *Table) Slots() []*Session                   // len Slots; nil for empty slots
func (t *Table) Get(key string) *Session
func (t *Table) Selected() int                       // slot index or -1
func (t *Table) Select(slot int)                     // ignores empty slots
func (t *Table) MoveSelection(delta int)             // next/prev occupied slot, wraps; selects first if none
func (t *Table) Visible(s *Session, now time.Time) State // State to paint, applying NeedsInputDelay
func (t *Table) All() []*Session                     // for /status, stable order
```

Rules:
- **Headless filter.** A session registered by SessionStart with `Attended=="0"` is ignored for its life (all
  later events for that session_id are dropped). `Attended=="1"` registers it. A session never registered
  (cm2d restarted mid-session) is accepted on its first UserPromptSubmit/PermissionRequest only if its
  Entrypoint header is `claude-desktop` or `cli` (best effort; may admit a nested headless run — acceptable).
  Sessions whose CWD has an IgnoreCWDPrefixes prefix are ignored.
- **Frontend.** HerdrPane set (from SessionStart env or Herdr join) -> herdr; Entrypoint claude-desktop -> desktop;
  cli -> terminal; else unknown.
- **Claude state machine.** UserPromptSubmit -> Working (clears Error, Question, Done). PermissionRequest -> append
  Pending (or Question=true if IsQuestion). PermissionReleased -> remove that Pending. PostToolUse -> clear Pending
  and Question, Working. Notification permission_prompt with no Pending -> NeedsInput (a backup cue).
  Stop -> clear Pending/Question, Done. StopFailure -> Error. SessionEnd -> Ended (keeps state; slot kept for
  EndedGrace). SessionStart source=resume on an ended session -> not ended.
  Every event updates LastActive. NeedsInput shows when Question, or any Pending older than NeedsInputDelay.
  Details the first draft left open (added after review): PermissionRequest sets State=Working and, like
  UserPromptSubmit, ends an ended session; a Notification `permission_prompt` with no Pending also takes a slot (it is
  slot activity); no other event un-ends a session.
- **Herdr.** For each agent in the snapshot: if Kind=="claude" and `agent_session.value` matches a known Claude
  session -> set its HerdrPane (Frontend herdr). Do not take Herdr's status for Claude sessions, except: Herdr
  `blocked` with no Pending -> NeedsInput (cross-check). Claude agents in Herdr with no session id yet: skip.
  Non-Claude agents: session `herdr:<pane>`, State from status (working->Working, blocked->NeedsInput,
  done->Done, idle/unknown->Idle). A pane gone from the snapshot: non-Claude session removed (slot freed);
  Claude session loses HerdrPane. Snapshot with Available=false: keep everything, drop nothing.
- **Slots.** A session gets a slot on its first activity (UserPromptSubmit, PermissionRequest, Herdr working or
  blocked); lowest free index. Slots are sticky. If none is free, evict the least recently active slot whose
  session is Idle (seen) or Ended; never evict Working, NeedsInput or Done-unseen. If nothing can be evicted, the
  session waits without a slot. Free a slot when: ended and EndedGrace passed; idle and IdleExpiry passed; Herdr
  pane closed. If the selected slot is freed, selection becomes -1.
  Sessions that wait for a slot take a freed one most recently active first, then in arrival order.
- **Dead sessions (added after review).** A Claude session in Working or NeedsInput (or with a Pending or a Question)
  that sent no event for 6 hours becomes Idle with Pending and Question cleared, so its slot can be reused (kill -9 and
  closed terminals send no SessionEnd). When Herdr has been unreachable for 30 seconds, non-Claude Herdr agents in
  Working or NeedsInput become Idle and forget their last Herdr status, so the first snapshot after Herdr returns sets
  it again. The set of ignored session ids keeps the newest 4096.

### 3.2 `internal/hooks` (HTTP server + held requests)

```go
type Server struct {
    Addr      string                 // "127.0.0.1:47731"
    Events    chan<- session.HookEvent // to the run loop; never block a request on a full channel (drop + count)
    CanHold   func() bool            // false when the pad is not connected: answer at once, hold nothing
    MaxHold   time.Duration          // default 590s
    Status    func() any             // GET /status body (JSON)
    Logger    *slog.Logger
}
func (s *Server) ListenAndServe(ctx context.Context) error // returns when ctx ends; binding the port is the single-instance lock
func (s *Server) Resolve(requestID string, d Decision) bool // run loop answers a held request
func (s *Server) ReleaseSession(sessionID string)             // empty 200 for every held request of the session
type Decision int // Allow, Deny, Pass
```

Endpoints:
- `POST /cm2d/v1/session` — from the SessionStart command forwarder; JSON `{payload: <hook json>, attended,
  entrypoint, herdr_pane}`; reply 200 at once; emit SessionStart event.
- `POST /cm2d/v1/event` — every other non-permission hook (UserPromptSubmit, Stop, StopFailure, SessionEnd,
  Notification, PostToolUse); reply 200 empty at once; read header `X-Cm2-Entrypoint`; emit event.
- `POST /cm2d/v1/permission` — PermissionRequest. If tool_name is AskUserQuestion, or `!CanHold()`: emit event
  (IsQuestion as appropriate) and reply empty 200 at once. Else: create RequestID, emit PermissionRequest, then
  wait for Resolve / ReleaseSession / client disconnect (request context) / MaxHold / server shutdown. Every
  exit path except Resolve(Allow|Deny) replies empty 200 (or nothing if the client is gone) and emits
  PermissionReleased. Request bodies are capped at 1 MiB.
- `GET /cm2d/v1/status` — JSON from Status().
Any other path: 404. Malformed JSON: 400, no event. Never panic on input.
Added after review:
- Every request must have a `Host` that names loopback (`127.0.0.1`, `localhost`, `[::1]`, any port), else 403. This
  stops DNS rebinding. Every POST must have `Content-Type: application/json` (parameters allowed), else 415. Claude Code
  and the forwarder send it (spike a8). This stops a web page from posting events with a simple cross-origin form POST.
- `Server.BodyTimeout` (default 10 s) limits the read of one body. A held request is not affected.
- `Status` may return an `error` value. The server answers 503 with its text.
- After registering a held request the server asks `CanHold` again. If the pad dropped in between, it does not hold.
- `Holds(requestID) bool` tells whether a request is held. `ReleaseAll()` releases every held request with an empty 200
  (and the `PermissionReleased` events). The daemon calls it when the pad goes away.

### 3.3 `internal/hookcfg` (settings.json install/uninstall, pure + file I/O)

```go
func Install(settingsPath, cm2dPath string, port int) (changed bool, backup string, err error)
func Uninstall(settingsPath string) (changed bool, backup string, err error)
```
Adds (idempotently; entries identified by URL containing "/cm2d/v1/", or by a command whose first word has the base
name `cm2d` and whose other words are `hook session-start` with an optional `--port N`; a foreign command that only
contains " hook session-start" is left alone, and `Install` refuses a binary not named `cm2d`):
SessionStart command hook `"<cm2dPath> hook session-start"`, plus ` --port N` when the port is not 47731 (timeout 5); http hooks to
`http://127.0.0.1:<port>/cm2d/v1/event` with timeout 5 for UserPromptSubmit, Stop, StopFailure, SessionEnd,
Notification, PostToolUse, each with `"headers":{"X-Cm2-Entrypoint":"$CLAUDE_CODE_ENTRYPOINT"}` and
`"allowedEnvVars":["CLAUDE_CODE_ENTRYPOINT"]`; PermissionRequest http hook to `/cm2d/v1/permission` with timeout
600 and the same header. No `onFailure`. Keep every other hook and key untouched; preserve key order and 2-space
indentation (the file round-trips through json with indent 2 today); write a timestamped backup next to the file
first; never write when nothing changes. Uninstall removes exactly what Install adds.

### 3.4 `internal/painter` (state -> lights)

```go
type Lights interface{ SetThreads(ctx context.Context, threads []Thread) error } // wraps v.oai.thstatus
type Thread struct{ ID, Color int; Brightness float64; Effect int; Speed float64 }
type View struct {
    Slots      [10]SlotView // empty slot = Present false
    Selected   int
    ApproveOn  bool          // selected session has a Pending (not a question)
    Flash      FlashKind     // none | approveRefused (red blink on the approve key, ~600 ms)
}
type SlotView struct{ Present bool; State session.State }
type Painter struct{ /* ... */ }
func New(l Lights, now func() time.Time) *Painter
func (p *Painter) Update(ctx context.Context, v View) error   // send only changed threads
func (p *Painter) Repaint(ctx context.Context) error          // send all 13 threads
func (p *Painter) Reconcile() <-chan time.Time                // fires ~500ms after the last change burst
```
Palette (fixed in code): Working blue 0x0050FF solid; NeedsInput amber 0xFFA000 breathing s=1;
Done green 0x00C853 solid; Error red 0xFF2020 solid; Idle white 0xFFFFFF solid. Brightness: selected slot 1.0,
others 0.45; Idle 0.25 if selected else 0.08. Empty slot off. Threads 10 and 11 (APPROVE): green 0x00C853
breathing s=1 when ApproveOn, else off; red solid during an approveRefused flash. Thread 12 (DENY): red 0xFF2020
solid at 0.6 when ApproveOn or the selected session has Question, else off.

### 3.7 `internal/daemon` (device supervisor + run loop) and `cmd/cm2d`

- Device supervisor: open the pad (`device.Open`), make a `device.Client`; on open failure retry every 3 s
  (log once per distinct error, e.g. not connected / Input Monitoring denied); on transport error or close,
  reopen; after each (re)connect `Painter.Repaint`. If the client reports foreign replies (another program on the
  pad), log a warning and stop painting for 30 s. Expose Connected() for hooks.CanHold.
- Run loop (one goroutine owns session.Table and Painter): select over hook events, Herdr snapshots
  (`herdr.Watcher` onChange -> channel), device notifications -> keys.Decoder, a 1 s ticker (Table.Tick +
  NeedsInputDelay transitions), Painter.Reconcile. After each change: build View, Painter.Update.
- The run loop never waits for the pad. It posts the newest View to a paint goroutine, which is the only caller of the
  Painter (it also handles the Painter's Reconcile and the repaint after a reconnect). A pad that takes writes but does
  not answer must not delay hook handling or `/status`. After 3 painter errors in a row (not counting a device error
  reply) the daemon closes the pad so that the supervisor opens it again.
- When the pad goes away the daemon releases every held request (`Server.ReleaseAll`) and clears every Pending. A
  PermissionRequest that the server did not hold (pad away, or already released) is dropped from the table at once.
- Pad notifications carry the time they arrived. The wide-key debounce uses that time, not the time the loop reads them.
- Key actions: SelectFocus -> Table.Select + Focuser.Focus (in a goroutine with timeout; result back to the
  loop) + Table.Focused. Move -> Table.MoveSelection. Approve -> if the selected session has a Pending:
  Server.Resolve(oldest, Allow); else Flash approveRefused. Deny -> if Pending: Resolve(oldest, Deny); if Question:
  nothing in v1 (log); else nothing. Approve/Deny never act on a session that is not selected.
- When a hook event ends a session's turn (PostToolUse, Stop, StopFailure, UserPromptSubmit, SessionEnd), call
  Server.ReleaseSession(session_id) as well as updating the table.
- `cm2d` commands: `run [--port N] [--no-device]`, `status` (GET /status, pretty print), `hook session-start`
  (forwarder: read stdin JSON + env, POST to /cm2d/v1/session with a 1 s total timeout, ALWAYS exit 0 and print
  nothing), `install-hooks [--port N] [--settings PATH] [--dry-run]`, `uninstall-hooks`, `setup
  [--layout config/layout.json] [--dry-run]` (the cm2probe keymap apply logic, moved into a shared package so
  both binaries use it), `herdr ...` (existing), `version`.
- Logs: log/slog text to stderr. Shutdown on SIGINT/SIGTERM: release every held request (empty 200), turn all
  lights off, close the pad, exit 0.

## 4. Tests (required; `go test -race`)

Unit tests per package, plus integration tests in `internal/daemon` with: devicetest fake transport (scripted
key notifications, captured thstatus), herdrtest fake Herdr server, and real HTTP requests to the hooks server.
Scenarios: two sessions working then done; approval held then APPROVE on the selected session -> allow reply;
APPROVE with another session selected -> refused flash, request still held; terminal-answer path (PostToolUse
releases the held request with empty 200); AskUserQuestion answered at once and shown as NeedsInput; client
disconnect releases; pad disconnected -> no hold; headless SessionStart (attended 0) never gets a slot; Herdr
non-Claude agent gets a slot and paints from Herdr status; Herdr Claude agent joins its hook session (one slot,
not two); slot eviction rules; dial moves selection; wide-key double report counts once; cm2d shutdown releases
held requests and turns lights off. No real pad, no real Herdr, no real Claude in unit/integration tests.
